Backend Bootcamp is a tutorials site that takes you from computer-science fundamentals to the principles, tools and mindsets of a production-ready backend engineer. Each tutorial teaches the reasoning, the build, the operation and the result.

## The 4-Part Framework

A tutorial that stops at the code teaches half of the job. The framework adds the reasoning before it and the operation and result after it.

1. **The Concept (why).** Why the feature exists, what it costs, and when it is the wrong tool.
2. **The Code (how).** Runnable examples, built step by step, that you can type, break and extend.
3. **The Operations (run).** How it behaves in real programs: configuration, debugging, alerts and a runbook.
4. **The Impact (measured).** What changed, in numbers, and what you can now build.

## Start at the level you are at

- **Foundations.** How computers, operating systems and software design work.
- **Core stack.** A language, a database and a queue. [Python](/python/) is live now.
- **Systems.** Reliable, observable, fast services.
- **Mastery.** Trade-offs, failure modes and ownership.

See the whole [learning map](/tutorials/).

## Plain promises about the content

- Every tutorial and tool is free, with no signup.
- Pages show when they were last updated, and are revised when the tools they describe change.
- Sample figures are labelled as samples. Measured results say how they were measured.
