faq:
  - q: What order should I follow the tutorials in?
    a: Follow the levels on the learning map from top to bottom. Foundations come first, then the core stack (a language, a database, a queue), then systems, then mastery. Skip any level whose topics you already know.
  - q: What is the 4-part framework?
    a: Every lesson is built from four parts. The Concept explains why a feature exists. The Code builds it step by step. The Operations part covers running and debugging it. The Impact part measures what changed.
  - q: Which tutorials are available now?
    a: Python Fundamentals and the Python Standard Library are live. Computer science fundamentals, databases, message queues and the rest of the map are releasing soon.
