faq:
  - q: Do I need programming experience to start Python Fundamentals?
    a: No. Python Fundamentals assumes no prior programming knowledge. It starts with installing Python and running your first script, then builds up to small projects.
  - q: Which Python version do the tutorials use?
    a: The examples target Python 3.11 or newer and use only the standard library unless a lesson says otherwise.
  - q: What is the difference between Python Fundamentals and the Standard Library tutorial?
    a: Fundamentals teaches the language itself, such as syntax, data structures, functions and classes. The Standard Library tutorial teaches the modules that ship with Python, such as pathlib, json, logging and asyncio, and how to choose between them.
