01 · The Concept · Why

A cache trades freshness for speed.

Understand the problem before the tool: what it solves, what it costs, and when to reach for something else.

02 · The Code · How

Build it, line by line.

def get_user(uid):
    hit = cache.get(uid)
    if hit: return hit
    user = db.fetch(uid)
    cache.set(uid, user, ttl=300)
    return user
